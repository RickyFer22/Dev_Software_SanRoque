Onboarding

Herramientas Desde Cero

Si es tu primera experiencia en entornos reales de programación cooperativa, estas son las tres herramientas fundamentales que utilizaremos todos los días:

01

Notion — Gestión de Objetivos

Es nuestro tablero de control. Al iniciar tu día, revisa la columna "Por Hacer", identifica el módulo técnico asignado, lee su documentación adjunta y arrastra la tarjeta a la columna "En Progreso".

02

GitHub — Control de Versiones

La nube de resguardo donde consolidamos el proyecto. Permite bajar la base del código y enviar tus progresos de forma ordenada con estos comandos:

bash · git workflow
# Clonar el proyecto (primera vez) git clone git@github.com:RickyFer22/Dev_Software_SanRoque.git # Actualizar tu proyecto local cada mañana git pull origin main # Subir tus avances listos y aprobados git add . git commit -m "feat: agrega estructura del modulo de turismo" git push origin main
03

Netlify — Publicación Automatizada

El servidor que publica la web en tiempo real. Conectado inteligentemente al repositorio GitHub: en el instante en que realizas un git push, Netlify compila y actualiza el portal en producción automáticamente.

Arquitectura Frontend

Estructura Modular del Portal

La arquitectura funcional del frontend está dividida de forma limpia y desacoplada en seis módulos principales:

🌲

Turismo & Cultura

Atractivos históricos, museos, agenda de la Fiesta Patronal, comparsas de carnaval y catálogos interactivos de hoteles y gastronomía local conectados a WhatsApp.

🏛️

Dependencia Municipal

Catálogo organizativo de secretarías y áreas gubernamentales, funciones institucionales, nombres de responsables y guías estructuradas de trámites.

⚽

Deportes

Fichas técnicas de clubes y ligas en curso (Futsal, etc.), disciplinas municipales y visualizador dinámico para reservas y alquileres de canchas.

📋

Servicios a la Comunidad

Cronogramas interactivos de recolección de residuos clasificados por barrios, centrales de remises y tablas de frecuencias de la Terminal de Ómnibus.

⛪

Culto

Guía de capillas y de la Parroquia, base informativa de sacerdotes y cuadrícula dinámica de horarios unificados de misas.

🛍️

Emprendedores Locales

Vitrina comercial para impulsar y dar visibilidad a artesanos y productores locales independientes clasificados por categorías.

Protocolo Obligatorio

Ciclo Operativo Diario

Para asegurar que avancemos sincronizados y sin interferir en los códigos de otros pasantes, cada jornada de trabajo debe respetar esta secuencia:

  1. 1
    Actualiza el estado de tu asignación en el tablero de Notion antes de comenzar cualquier tarea.
  2. 2
    Sincroniza tus archivos locales ejecutando git pull origin main para evitar conflictos con otros pasantes.
  3. 3
    Desarrolla interfaces responsivas con HTML5 semántico, CSS y JavaScript Vanilla. Visualiza los cambios en tiempo real con la extensión Live Server.
  4. 4
    Guarda y envía tus avances a GitHub con git add . + git commit + git push.
  5. 5
    Espera ~2 minutos e ingresa al enlace de Netlify para certificar el correcto despliegue de tu sección en producción.
  6. 6
    Mueve la tarjeta en Notion al estado "Finalizado" y notifica al equipo sobre el avance completado.
